## Specs

- **Aspect ratio:** portrait, ~**1024 × 1536** (2:3). Any 2:3 portrait size works; larger is fine.
- **Format:** `.jpg` (progressive JPEG recommended for faster loading).
- **Keep the filenames above** — replacing a file with the same name updates the cover everywhere on the site with no code changes.

The current files in this folder are the finished covers already sized to 1024 × 1536.
